# CRUNCH! bot 🍪

Бесплатная печенька за подписку: друг-реферал → QR-код → скан на кассе.

## Запуск
1. @BotFather → `/newbot` → имя `crunch_bot` → токен.
2. **Добавь бота админом в канал @crunch_krd** с правом «Приглашать пользователей по ссылке» (без этого не работают личные ссылки и подсчёт друзей).
3. `cp .env.example .env` — впиши `BOT_TOKEN` и `ADMIN_IDS` (свой id покажет команда `/id` боту).
4. `pip install -r requirements.txt && python bot.py`
   или Docker: `docker build -t crunch-bot . && docker run -d --restart=always --env-file .env -v $PWD/data:/app/data crunch-bot`

## Как работает
- Клиент подписан на канал → «моя ссылка» создаёт **личную инвайт-ссылку** канала.
- Бот ловит вступления по ссылке (`chat_member`). Один человек засчитывается один раз, самоприглашение не считается.
- «Готово»: бот перепроверяет, что клиент и друзья всё ещё подписаны, и выдаёт QR-карточку с кодом.
- Новый код — только за новых друзей (`REQUIRED_FRIENDS` штук на каждый).

## Касса
Наведи камеру телефона на QR клиента → откроется бот → «🍪 выдать печеньку». Повторно код не сработает.
Если камера не открывает ссылку: `/redeem КОД`. Статистика: `/stats`. Кассиров добавляй в `ADMIN_IDS`.
